## Project Description

CrushRadar™ is an unnecessarily advanced system designed to solve a problem that absolutely does not exist.

It allows users to search for their crush, send crush requests, detect mutual crushes, and use GPS-powered radar to determine how suspiciously close their crush is.

Because apparently, simply talking to someone wasn't enough.

---

## The Problem (that doesn't exist)

Have you ever wondered:

> "Is my crush somewhere nearby?"

Probably not.

But CrushRadar™ decided this was an extremely serious technological problem that needed solving.

The project addresses the completely unnecessary problem of knowing how close your crush is without having to actually ask them.

---

## The Solution (that nobody asked for)

CrushRadar™ combines social networking, GPS, distance calculation, notifications, and dramatic UI effects to answer one extremely important question:

> **HOW CLOSE IS MY CRUSH?**

Users can create profiles, search for other users, select someone as their crush, and receive notifications when someone selects them.

If two users select each other, the system detects a:

> 💘 **MUTUAL CRUSH DETECTED**

The project also includes a GPS-powered Crush Radar that calculates the approximate distance between two users.

Depending on the distance, the system displays increasingly dramatic warnings:

- 🟢 SAFE — They're basically in another dimension.
- 🟡 NEAR — Potential sighting.
- 🟠 WARNING — Things are getting suspicious.
- 🔴 DANGER — STOP LOOKING AROUND.
- 🚨 PANIC — ABORT. THEY ARE WAY TOO CLOSE.

As the crush gets closer, the frontend's fake heartbeat becomes increasingly dramatic.
